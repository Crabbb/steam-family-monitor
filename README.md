# Steam Family Monitor 🎮

Self-hosted сервис: следит за Steam-библиотеками нескольких человек, присылает уведомления в Telegram и даёт веб-панель для настройки.

## Возможности

- **Новые игры.** Опрашивает библиотеки по расписанию и присылает карточку покупки: цена RU и KZ, режимы игры, семейная библиотека, Metacritic, совместимость со Steam Deck. Первая синхронизация проходит молча, покупка бандла приходит одним дайджестом.
- **Цены и скидки.** Команда `/price` показывает цены Steam RU и KZ (с пересчётом в рубли по курсу ЦБ), цену Steam-ключа на plati.ru и поддержку семейной библиотеки. Watchlist сторожит скидки в обоих регионах и сообщает исторический минимум.
- **Бесплатные раздачи.** Находит игры со скидкой 100% «навсегда», отсеивает бесплатные выходные, не присылает одну раздачу дважды, при желании пропускает игры, которые уже есть у всех.
- **100% достижений.** Замечает полностью закрытые игры, добавляет статистику SteamHunters, редчайшее и последнее достижение.
- **Веб-панель.** Пользователи, история уведомлений, watchlist, расписания, включение и выключение отдельных функций.
- **Самодиагностика.** `/api/health` и панель на дашборде показывают, когда каждая фоновая задача отработала в последний раз: тишина сервиса отличима от его поломки. О недоступном профиле Steam сообщает отдельно.

## Команды бота

| Команда | Что делает |
|---|---|
| `/price <название или appId>` | цены Steam RU и KZ, plati.ru, семейная библиотека |
| `/watch <название или appId>` | следить за скидками на игру |
| `/unwatch <название или appId>` | убрать игру из отслеживания |
| `/watchlist` | список отслеживаемых игр |
| `/status` | когда последний раз проверялись библиотеки, скидки и раздачи |
| `/help` (или `/start`) | список команд |

## Что понадобится

Ничего из этого не хранится в файлах репозитория: секреты задаются на странице **Settings** после первого старта, отслеживаемые люди — на странице **Users**. Всё лежит в локальной SQLite.

| Данные | Формат | Где взять |
|---|---|---|
| Steam Web API key | 32 hex-символа | https://steamcommunity.com/dev/apikey |
| Telegram bot token | `<цифры>:<буквы и цифры>` | `@BotFather` → `/newbot` |
| Telegram chat id | целое число, у групп и каналов отрицательное вида `-100…` | напишите в нужный чат и откройте `https://api.telegram.org/bot<token>/getUpdates`, поле `chat.id` |
| SteamID64 каждого отслеживаемого | 17 цифр, начинается на `7656119…` | вводится как есть; кастомные адреса вида `/id/nickname` сервис не разрешает |

Ключ Steam выдаётся только на аккаунт с покупкой и привязанным телефоном. Чтобы бот писал в канал, добавьте его админом с правом публикации; в группу достаточно просто добавить.

**Профиль Steam должен быть открыт** — «Игровые данные: для всех». У закрытого профиля запросы вернут пустой список или 403: сервис не упадёт, но уведомлений по этому человеку не будет, и через три неудачные проверки подряд он напишет об этом в чат.

Остальные источники — Steam Store, SteamSpy, SteamHunters, ProtonDB, курс ЦБ, plati.ru — запрашиваются анонимно, ключи не нужны. Языковые модели не используются, ключи AI-провайдеров не нужны.

## Безопасность

**В сервисе нет аутентификации.** Веб-панель и API открыты любому, кто достучится до порта, а `GET /api/settings` возвращает сохранённые токены в открытом виде.

- Не публикуйте порт в интернет. Дефолтный `compose.yml` намеренно биндит его на `127.0.0.1`.
- Для удалённого доступа — VPN, SSH-туннель или reverse proxy с авторизацией перед сервисом.
- Файл SQLite содержит токены в открытом виде: считайте его секретом и шифруйте бэкапы.
- Бот отвечает любому, кто ему напишет: chat id входящих команд не проверяется, поэтому посторонний может выполнить `/price` и изменить общий watchlist через `/watch`. Если это нежелательно, не публикуйте имя бота или добавьте проверку `msg.chat.id` в `handleUpdate` (`src/lib/telegramBot.ts`).

## Запуск

### Docker Compose

```bash
git clone https://github.com/Crabbb/steam-family-monitor.git
cd steam-family-monitor
docker compose up -d --build
```

Откройте `http://127.0.0.1:8081` и заполните Settings.

База лежит в именованном томе `steam-monitor-data`. Свой путь на хосте или другой порт задаются файлом `compose.override.yml` — он в `.gitignore` и в репозиторий не попадёт:

```yaml
services:
  steam-monitor:
    ports:
      - "127.0.0.1:8081:3000"
    volumes:
      - /path/to/your/data:/app/prisma/data
```

Если сервис уже работал с хостовым каталогом, а вы переходите на именованный том — сделайте бэкап каталога с базой и проверьте `docker compose config` перед пересозданием контейнера, иначе он поднимется с пустой базой.

### Без Docker

Нужен Node.js 24 (минимум 20.9) и доступ к Steam и Telegram из сети.

```bash
git clone https://github.com/Crabbb/steam-family-monitor.git
cd steam-family-monitor
cp .env.example .env
npm ci
npx prisma generate
npx prisma db push
npm run build && npm start
```

Открывается на `http://localhost:3000`. Путь к базе берётся из `DATABASE_URL`, по умолчанию `file:./dev.db`. Для долгоживущего запуска используйте `systemd`, `pm2` или `supervisord` и делайте бэкап базы перед обновлением.

## Настройки

Задаются на странице **Settings** и хранятся в базе: ключ Steam, токен и chat id Telegram, интервал опроса библиотек, watchlist (включение, интервал, минимальная скидка), раздачи (включение, регионы, часы работы, глубина поиска), достижения (включение, часы работы, лимит сканирования, SteamHunters). Таймзона расписаний задаётся там же, таймзона контейнера — переменной `TZ`.

## Стек

Next.js 16 (App Router), Node.js 24, SQLite + Prisma 7, `node-cron`, Telegram Bot API. Развёртывание — Docker.
